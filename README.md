# Tehran Tourism Website

A modern tourism website for discovering popular tourist attractions in Tehran.

This project is built with **HTML, CSS, JavaScript, Python and Django**.

## Features

* Modern and responsive UI
* Tourist attraction cards
* Attraction title and description
* Location information
* Category filtering
* Mobile-friendly navigation
* Django backend
* Django Models and ORM
* Data management through Django

## Technologies

* HTML5
* CSS3
* JavaScript
* Python
* Django
* SQLite

## Database

The project currently uses **SQLite** during development.

**PostgreSQL has not been connected to the project yet.**

The project is planned to be migrated to PostgreSQL in a future version.
